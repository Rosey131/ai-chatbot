1) Use the app (no programming needed)
--------------------------------------
  1. Open Windows-App and run ALTREX-CODE-Setup-0.1.0-x64.exe
     (or ALTREX-CODE-Portable-0.1.0-x64.exe to run without installing).
  2. Windows may show "Windows protected your PC" because the app is not code-signed.
     Click "More info" -> "Run anyway".
  3. On first launch, the "Add a main AI provider" window appears. Choose one:
       - crax-gpt (free): click "Open crax-gpt", sign in, create an API key,
         paste it into ALTREX and click "Connect".
       - Google Gemini / NVIDIA / OpenRouter / Groq: click "Get API key",
         create a key on the official site, then "Add key" and paste it.
       - Ollama (runs on your PC): install Ollama from ollama.com, run
         "ollama pull qwen2.5-coder:7b-instruct", then "Connect".
       - ChatGPT Codex: install the OpenAI Codex CLI and sign in once,
         then pick "ChatGPT Codex" in the AI mode menu for Build tasks.
  4. Click "Open project", choose a folder, type what you want and press Ctrl + Enter.
  5. The first task on a project asks "Allow cloud AI" before any code is sent to a
     cloud provider. Click "Allow and run task" (or use "Local only").

  Your API keys are encrypted on your computer and never shown again.
  Uninstalling the app never deletes your projects.


2) Build it yourself from the source code
-----------------------------------------
  Requirements: Windows 10/11 x64, Node.js 22+, pnpm 11, Git.

    cd ALTREX-CODE-source
    pnpm install
    pnpm dev          (run in development mode)
    pnpm test         (automated tests, no API keys needed)
    pnpm dist:win     (build your own installer + portable EXE into release\)

  See ALTREX-CODE-source\README.md for details and troubleshooting.


Verify the downloads (optional)
-------------------------------
  In PowerShell, inside Windows-App:
    Get-FileHash .\ALTREX-CODE-Setup-0.1.0-x64.exe -Algorithm SHA256
  The value must match the line in SHA256SUMS.txt.
